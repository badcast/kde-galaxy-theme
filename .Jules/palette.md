## 2024-05-24 - Aurorae Theme Edge Clipping & Gradients
**Learning:** In KDE Aurorae window decorations, the `.rc` configuration settings for `TitleEdge` and `TitleBorder` must exactly match the pixel geometry of the corner and edge elements in `decoration.svg` (e.g., 16px). A mismatch causes the engine to abruptly crop or squish elements. When applying gradients to 1px strokes in KWin, replacing thin `<line>` elements with solid `<rect>` blocks creates massive visual regressions; instead, keep the 1px `<line>` and apply the gradient to its `stroke`.
**Action:** When fixing clipped borders in Aurorae, always synchronize the `.rc` layout values with the SVG bounding boxes. When enhancing 1px SVG lines with gradients, apply the gradient to the `stroke` attribute, do not change the element to a solid block.
