# 🌌 Galaxy Theme KDE for KDE Plasma 6 (>= 6.7)

**Автор**: badcast (<lmecomposer@gmail.com>)  
**Сайт**: <https://github.com/badcast/kde-galaxy-theme>  
**Проект**: Galaxy Theme KDE  
**Лицензия**: GPL-3.0+  

Современная, стильная и глубоко проработанная тема рабочего стола **Galaxy Theme KDE (Космос)** для **KDE Plasma 6**.

Включает в себя полный комплекс визуального оформления: цветовую схему, 9-slice тему Plasma, оконные декорации Aurorae, 100% векторные SVG иконки, космические курсоры, стиль приложений Kvantum и анимированный Splash Screen.

---

## ✨ Что входит в состав сюиты:

1. **🎨 Цветовая схема (`GalaxyDark.colors`)**:
   - Глубокие фоны космической бездны (`#0B0E17`, `#0F1426`, `#1A2238`).
   - Светящиеся неоновые акценты: Пульсар фиолетовый (`#00F0FF`), Туманность маджента (`#00F0FF`), Звездный циан (`#00F0FF`), Сверхновая золото (`#FBBF24`) и Зеленое полярное сияние (`#10B981`).
   - Идеальный контраст и четкость шрифтов.

2. **🪐 Plasma 6 Desktop Theme (`Galaxy-Dark`)**:
   - Соответствие стандарту `metadata.json` (KPlugin).
   - Glassmorphic 9-slice панели (`panel-background.svg`) с адаптивной прозрачностью и неоновой кромкой.
   - Стилизованные виджеты задач (`tasks.svg`) в стиле Apple Dock (светящаяся LED-точка под запущенными окнами и неоновая капсула у активного окна), кнопок (`button.svg`), слайдеров, скроллбаров, всплывающих подсказок (`tooltip.svg`), часов и индикаторов загрузки.

3. **🪟 Оконные декорации Aurorae (`Galaxy-Dark-Aurorae`)**:
   - Глубокие обсидиановые заголовки (`#0F1426` / `#0B0E17`) с тонкой неоновой верхней гранью (`#00F0FF` / `#00F0FF`).
   - Адаптировано из проекта `phuturista-gamer-blue`.
   - Кнопки управления окнами (`close`, `maximize`, `minimize`, `restore` и др.) с 8 состояниями и неоновой подсветкой при наведении.

4. **✨ Набор SVG-иконок (`Galaxy-Icons`)**:
   - **100% векторный SVG формат** — более 380 иконок и симлинков, четкость на любых разрешениях (4K, HiDPI).
   - Офисные документы (Word, Excel, PowerPoint, LibreOffice Writer/Calc/Impress/Base/Draw/Math, PDF, ePub).
   - Архивы (ZIP, RAR, 7Z, TAR, GZ, XZ, ZST, ISO, DEB, RPM, APK).
   - Системный трей и уведомления в едином стиле Wi-Fi (чистый минималистичный line-art 24×24): Wi-Fi, Батарея (11 уровней + зарядка), Bluetooth, Звук, Микрофон, Ночной режим, Klipper, Plasma Vault.

5. **🛸 Тема курсоров (`Galaxy-Cursors`)**:
   - Указатели со звездным градиентом и глубокими тенями для отличной видимости на светлых и темных фонах.
   - Анимированный спиннер загрузки в виде вращающейся галактической спирали.
   - Мульти-размерная компиляция под X11 и Wayland (24, 32, 48, 64px).

6. **💫 Стиль приложений Kvantum (`Galaxy-Dark`)**:
   - Адаптирован из KvMojave с полупрозрачными матовыми поверхностями и космической палитрой.

7. **🚀 Анимированный Splash Screen (`org.galaxy.desktop`)**:
   - Экран запуска сессии на базе QtQuick / Kirigami с эффектом вращающегося галактического ядра и орбитального пульсара.

8. **📦 Глобальная тема (Look-and-Feel)**:
   - Связывает все компоненты в единое целое для мгновенной установки в один клик.

---

## 📥 Установка

### Быстрая установка и мгновенное применение:
```bash
./install.sh --apply
```

### Пересборка всех ассетов и установка:
```bash
./install.sh --build --apply
```

### Удаление:
```bash
./install.sh --uninstall
```
