# 🌌 Galaxy Theme KDE for KDE Plasma 6 (>= 6.7)

**Автор**: badcast (<lmecomposer@gmail.com>)  
**Сайт**: <https://github.com/badcast/kde-galaxy-theme>  
**Проект**: Galaxy Theme KDE  
**Лицензия**: GPL-3.0+  

Современная, стильная и глубоко проработанная тема рабочего стола **Galaxy Theme KDE (Космос)** для **KDE Plasma 6**.

Включает в себя полный комплекс визуального оформления: цветовую схему, 9-slice тему Plasma, оконные декорации Aurorae, 100% векторные SVG иконки, космические курсоры, 4K обои и анимированный Splash Screen.

---

## ✨ Что входит в состав сюиты:

1. **🎨 Цветовая схема (`GalaxyDark.colors`)**:
   - Глубокие фоны космической бездны (`#0B0E17`, `#0F1426`, `#1A2238`).
   - Светящиеся неоновые акценты: Звездный циан (`#00F0FF`), Пульсар (`#00F0FF`), Сверхновая золото (`#FBBF24`) и Зеленое полярное сияние (`#10B981`).
   - Идеальный контраст и четкость шрифтов.

2. **🪐 Plasma 6 Desktop Theme (`Galaxy-Dark`)**:
   - Соответствие стандарту `metadata.json` (KPlugin).
   - Glassmorphic 9-slice панели (`panel-background.svg`) с адаптивной прозрачностью и неоновой кромкой.
   - Стилизованные виджеты задач (`tasks.svg`), кнопок (`button.svg`), списков (`viewitem.svg`), слайдеров, скроллбаров, всплывающих подсказок (`tooltip.svg`), часов и индикаторов загрузки.

3. **🪟 Оконные декорации Aurorae (`Galaxy-Dark-Aurorae`)**:
   - Глубокие обсидиановые заголовки (`#0F1426` / `#0B0E17`) с тонкой неоновой верхней гранью (`#00F0FF`).
   - Кнопки управления окнами (`close`, `maximize`, `minimize`, `restore`, `help` и др.) с неоновой подсветкой при наведении и векторной графикой.

4. **✨ Набор SVG-иконок (`Galaxy-Icons`)**:
   - **100% векторный SVG формат** — более 400 иконок и симлинков, четкость на любых разрешениях (4K, HiDPI).
   - Офисные документы, архивы, плееры, принтеры, системные диалоги (`dialog-error`, `dialog-warning`, `dialog-question`).
   - Системный трей и уведомления: Wi-Fi, Батарея, Bluetooth, Звук, Микрофон, Ночной режим, Klipper, Plasma Vault.

5. **🛸 Тема курсоров (`Galaxy-Cursors`)**:
   - Указатели со звездным градиентом и глубокими тенями для отличной видимости на светлых и темных фонах.
   - Анимированный спиннер загрузки в виде вращающейся галактической спирали.
   - Мульти-размерная компиляция под X11 и Wayland (24, 32, 48, 64px).

6. **🌌 4K Космические Обои (`Galaxy-Dark`)**:
   - Векторная 4K SVG и lossless PNG 3840×2160 с туманностями и звездами.

7. **🚀 Анимированный Splash Screen (`org.galaxy.desktop`)**:
   - Экран запуска сессии на базе QtQuick / Kirigami с эффектом вращающегося галактического ядра и орбитального пульсара.

8. **📦 Глобальная тема (Look-and-Feel)**:
   - Связывает все компоненты в единое целое для мгновенной установки в один клик. Использует нативный стиль Breeze с палитрой GalaxyDark.

---

## 📥 Установка

### Быстрая установка и мгновенное применение:
```bash
./install.sh --apply
```

### Пересборка всех ассетов и установка:
```bash
./install.sh --build --apply
```

### Удаление:
```bash
./install.sh --uninstall
```
